# TA Dashboard - CarDekho Group

Professional Talent Acquisition dashboard with Google Sheets integration.

## Features
- **Dashboard**: Real-time hiring metrics and KPIs
- **Position Tracker**: Full position-level drill-down  
- **CHRO View**: Executive-level hiring overview with funnel, velocity, and BU scorecard

## Usage
1. Open the dashboard
2. Click "Sync data" to pull from Google Sheets
3. Use filters to slice by Business Unit, Leader, Status, etc.
4. Export to CSV for reporting
